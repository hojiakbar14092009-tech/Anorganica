## How to author a lesson (cheap path)
1. Print source pages (pdfPage..endPage from docs/SOURCE_MAP.md):
   `node --input-type=module -e "import fs from 'fs';const p=JSON.parse(fs.readFileSync('reference/text/g8.json'));for(let i=174;i<=176;i++)console.log(i,p[i-1].slice(0,1800))"`
   (`reference/text/g{8,9}.json` is regenerated by `npm run source-map`.)
2. Write `content/lessons/g{grade}-s{n}.json` — copy structure of g8-s32.json. Original wording; cite pages; ≥4 questions;
   textbook errors → `clarifications`. Reaction cell `""` = physical step without equation.
3. `npm run validate:content` (schema, page range, atom/charge balance, answer keys, unique stems).
4. Update the counts above; `node` one-liner in git history (commit "docs: exam mapping") regenerates the EXAM_BLUEPRINT table.
